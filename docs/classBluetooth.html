Detailed Description

Handles Bluetooth communication for controlling the buggy.

This class processes incoming Bluetooth commands, sends debug data, and manages parameter updates for different buggy movement modes.

◆ processCommand()

void Bluetooth::processCommand ( )

Processes received commands from the buffer.

Reads each character from the circular buffer and forwards it to parseCommand. Commands are only processed if the buggy is not in a movement state.
