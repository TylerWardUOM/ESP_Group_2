\doxysubsection{Detailed Description}
Handles \doxylink{classBluetooth}{Bluetooth} communication for controlling the buggy. 

This class processes incoming \doxylink{classBluetooth}{Bluetooth} commands, sends debug data, and manages parameter updates for different buggy movement modes.
